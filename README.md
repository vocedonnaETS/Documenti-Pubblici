# Documenti pubblici di Voce Donna Pordenone

Questo repository raccoglie i documenti che l'associazione **Voce Donna
Pordenone**, centro antiviolenza, mette a disposizione del pubblico:
materiali informativi, guide, opuscoli, documenti istituzionali.

I file sono in formato PDF, organizzati per cartelle. Ogni documento
riporta al suo interno data e versione.

Salvo diversa indicazione scritta nel documento stesso, i contenuti di

licenza **Creative Commons Attribuzione – Non commerciale – Non opere
derivate 4.0 Internazionale (CC BY-NC-ND 4.0)**.

In pratica, chiunque può:

- **scaricare, stampare e ridistribuire** i documenti, anche in gran
  numero, purché **integri**, senza modifiche né tagli;
- **citarli**, indicando "Voce Donna Pordenone" come fonte e, dove
  possibile, il collegamento a questo repository.

Non è consentito:
